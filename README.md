## Description

This assignment uses jQuery for selectors, CSS changes, effects, DOM manipulation, events, and animations. Each task is on a separate HTML page with navigation between tasks.

## Tasks

- Task 0: Setup and `$(document).ready()`
- Task 1: Selectors by ID, class and tag; `.text()`, `.html()`, `.css()`
- Task 2: `.hide()`, `.show()`, `.toggle()`
- Task 3: `.fadeIn()`, `.fadeOut()`, `.fadeToggle()`
- Task 4: `.slideUp()`, `.slideDown()`, `.slideToggle()`
- Task 5: `.append()`, `.prepend()`, `.remove()`
- Task 6: Change image `src` and link `href` using `.attr()`
- Task 7: Name and Email live preview using `.val()` and `.text()`
- Task 8: Basic `.animate()` size and position change
- Task 9: Sequential animations
- Task 10: Combined animation (size, movement and opacity)
- Task 11: Mini Project — Accordion Menu

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` using Live Server (or a web browser).
3. Use the navbar to open Task 0–11.
4. For Task 0, open Developer Tools → Console to see `jQuery is ready!`.

jQuery 3.7.1 is loaded from the CDN, so an internet connection is required.

## Files

- `index.html`, `task1.html`–`task11.html` — separate task pages
- `CSS/style.css` — common styles
- `JS/task0.js`–`JS/task11.js` — jQuery code
- `images/image1.svg`, `images/image2.svg` — local images for Tasks 3 and 6
